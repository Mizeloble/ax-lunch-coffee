# components/

모바일 퍼스트. 데스크탑은 부수적.

## 규칙
- 한국어 문자열은 `src/lib/i18n.ts`에서만 import. 컴포넌트 안에 인라인 금지.
- 터치 타겟 최소 44px (`py-3` 이상).
- 모달/시트는 화면 하단에서 올라오는 바텀시트 패턴(`items-end sm:items-center`).
- 색이 의미를 나눈다: **앰버(amber-400) = 내 차례·선택·CTA**, **빨강(red-500) = 벌칙·위반·꼴찌**, zinc-800/900 = surface, emerald = 안전·면제. 빨강을 버튼에 쓰면 "위험/삭제"로 읽히니 CTA는 계속 앰버.
- 색만으로 상태를 구분하지 않는다 — 벌칙/면제 같은 결과는 `✕`/`✓` 라벨을 함께 붙인다(색약 + 단톡방 저화질 캡처).
- 본문 최소 13px, 목록·설명 14~15px. 10~12px 층은 회식 조명에서 안 읽힌다.

## 안전영역
하단 고정 CTA는 `pb-[max(env(safe-area-inset-bottom),16px)]`로 노치/홈인디케이터 회피.

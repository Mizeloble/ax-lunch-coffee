# store-assets/ — 앱인토스 콘솔 등록물

`src/`의 HTML을 Playwright 뷰포트 캡처로 `out/` PNG를 만든다 (정확한 픽셀 크기 보장).
재생성: miniapp dev 서버(:5173) 실행 → `/store-assets/src/<파일>.html`을 해당 크기 뷰포트로 캡처.
게임 스크린샷은 프로덕션(fly.dev)에서 실제 방(수동 참가자 지훈·서연·민준·하늘)을 돌려 캡처 — 무편집.

| out/logo-600.png | 600×600 | 앱 로고 + 다크모드 앱 로고 (겸용) |

### 원스토어용 1024×578 (16:9)

원스토어 이미지 슬롯이 **1024×578만** 허용해서 별도 제작 (앱인토스 규격과 다름).

게임 컷은 전부 프로덕션에서 실제 방(지훈·서연·민준·하늘·다온)을 돌려 **무편집** 캡처.

| 파일 | 내용 | 권장 순서 |
|---|---|---|
| out/s-lobby-1024.png | 로비 — 방 코드 + QR 초대 | 1 (앱을 어떻게 쓰는지) |
| out/shot-race-1024.png | 마블 레이스 진행 | 2 (대표 게임) |
| out/shot-result-1024.png | 결과 — 벌칙 발표·전체 순위 | 3 (핵심 가치) |
| out/s-reaction-1024.png | 반응속도 "지금!" GO 순간 | 4 (게임 다양성) |
| out/s-quiz-1024.png | 일반 상식 퀴즈 — 문제·4지선다 | 5 |
| out/s-games-1024.png | 게임 라인업 6종 목록 | 6 (구색) |
| out/banner-1024.png | 배너·대표 이미지 슬롯 (`src/banner-1024.html`에서 캡처) | 배너 슬롯 전용 |

무편집 실플레이 컷인 뒤 두 장은 나중에 앱인토스 등급분류가 요구하는
"플레이 화면 4장(스토어 2 + 앱인토스 2)" 증빙에도 그대로 쓸 수 있다.

카피 기조: 전연령 파티게임 — 음주·술자리 표현 배제 (docs/toss-miniapp-review.md §3-1).

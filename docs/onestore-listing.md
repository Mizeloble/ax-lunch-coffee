# 원스토어 등록 입력값 (등급분류용)

목적은 유통이 아니라 **자체등급분류 번호 취득** — 앱인토스 출시의 법적 요건.
맥락은 [toss-miniapp-review.md](toss-miniapp-review.md) §1-3.

## 등록 절차

[개발자센터](https://dev.onestore.co.kr) → **Apps > 상품현황 > [신규 상품 등록]**

1. **서비스 구분**: `정식 출시` (베타는 등급분류 목적에 맞지 않음)
2. **OS**: `Android`
3. **기본 정보**
   - 상품제목(최대 50자): `복불복파티`
   - 기본언어: 한국어
   - **패키지 네임: `com.mizeloble.bokbulbok`** ⚠️ **등록 후 변경 불가** — APK에 서명된 값과 반드시 일치
4. **카테고리**: **게임** 계열로 선택. 게임 카테고리는 게임물만 서비스 가능하고,
   나중에 다른 카테고리에서 게임으로 바꾸면 재검증을 다시 받는다 → 처음부터 게임으로.
5. **상세 정보**: 아래 [앱 정보](#앱-정보)의 설명·아이콘·스크린샷 입력
6. **바이너리 업로드**: `app-release-signed.apk`
7. **등급분류(IARC) 설문**: 아래 [설문 답안](#자체등급분류-설문-iarc--사실대로)대로 응답 →
   제출하면 등급이 자동 부여된다(원스토어가 자체등급분류사업자)
8. **검수 요청** → 통과 시 스토어 전시 + 등급분류 번호 확정

> 원스토어 등급으로 앱인토스 제출이 가능한지는 앱인토스 콘솔팀이 "가능하다"고 답변한
> [커뮤니티 스레드](https://techchat-apps-in-toss.toss.im/t/topic/1689)와, 실제로 통과시킨
> [사례](https://techchat-apps-in-toss.toss.im/t/topic/3570)로 확인됨.

## Android 개발자 인증 (2027, 지금은 무영향)

업로드 중 뜨는 "Android 개발자 인증 대상 여부 확인" 팝업 관련. **업로드를 막지 않으니
지금은 닫고 진행한다.**

[구글 정책](https://developer.android.com/developer-verification): 인증 안 된 개발자의 앱은
인증 Android 기기에 설치가 제한된다. 2026-09 브라질·인도네시아·싱가포르·태국 시작,
**한국 포함 글로벌은 2027년**.

우리에게 미치는 영향:
- **토스 미니앱은 대상 아님** — 안드로이드 앱이 아니라 토스 웹뷰에서 도는 웹이다. 본 제품은 무관.
- **원스토어 APK는 2027부터 대상.** 다만 이 앱의 존재 목적은 등급분류 번호 취득이고,
  **번호는 발급 시점에 확정**되므로 나중에 설치가 제한돼도 등급 자체는 유효하다.
- 원스토어를 실제 유통 채널로 쓸 생각이면 2027 전에 인증하면 된다.

인증 옵션([FAQ](https://developer.android.com/developer-verification/guides/faq)):

| | 개인 계정 | Limited Distribution |
|---|---|---|
| 비용 | **$25** | 무료 |
| 확인 | 정부 발급 신분증 | 불필요 |
| 제한 | 없음 | **최대 20기기** — 스토어 배포엔 부적합 |

개인 계정은 **사업자등록·D-U-N-S 불필요**(조직 계정만 D-U-N-S). 즉 필요해지면 신분증 +
$25로 해결되고, 구글 플레이 경로처럼 테스터 12명×14일 같은 조건은 없다.

## 수집정보 및 지식재산권

| 문항 | 답 | 근거 |
|---|---|---|
| 지식재산권 사용 여부 | **아니오** | 타인의 캐릭터·브랜드·음원·유료 폰트를 쓰지 않는다. 퀴즈는 자체 작성 문제 풀(`src/games/trivia/questions.ts`), 효과음은 에셋 없이 WebAudio 합성(`src/lib/sfx.ts`), 아이콘·이미지는 직접 제작. 오픈소스 라이브러리(React·box2d-wasm 등)는 허용적 라이선스라 이 문항이 묻는 "이용권한 증빙이 필요한 타인 IP"에 해당하지 않는다 |
| 정보 수집 및 공유 여부 | **예** | 문항 정의가 "**사용자 기기에 저장**하거나 서버·타사로 전송"이라 로컬 저장만으로도 해당 |

**하위 항목별 답** (원스토어가 Play Data Safety와 같은 범주를 쓴다):

| 항목 | 답 | 근거 |
|---|---|---|
| 사진 및 동영상 / 오디오 / 파일 및 문서 | 아니오 | 카메라·마이크·파일 접근 권한을 쓰지 않는다 |
| 메시지 | 아니오 | 채팅·메시지 기능 없음 |
| **앱 활동** | **예** | CF 분석의 페이지뷰·유입, 서버가 기록하는 게임 입력·방 생성/라운드 카운터, 닉네임(사용자 생성 콘텐츠) |
| **앱 정보 및 성능** | **예** | 크래시 리포팅은 없으나 CF Web Analytics가 로딩 성능(Core Web Vitals)·브라우저/OS를 수집 |
| **기기 또는 기타 ID** | **예** | `bbk:identity`의 **플레이어 토큰** — 재접속 복구용으로 기기에 영구 저장하고 서버로 전송하는 유사 식별자. 광고 ID·IMEI는 미사용 |

수집 목적을 묻는 후속 화면: **앱 활동·기기 ID = "앱 기능"**(게임 진행·재접속 복구),
**앱 정보 및 성능 = "분석"**. 광고·개인 맞춤 용도 없음.

> 판단 원칙: 과다 신고는 설명하면 되지만 **누락은 정책 위반**이다. 애매하면 `예` 쪽.

**세부 데이터 목록** (자유 기술란이 있으면):

- **기기 내 저장(localStorage/sessionStorage)**: `bbk:identity`(닉네임 + 플레이어 토큰),
  `bbk:sound`(사운드 설정), `marble.haptics.muted`(진동 설정), `bbk:consent`(광고 동의),
  `bbk:host:<방코드>`(호스트 권한 토큰)
- **서버 전송**: 닉네임, 게임 입력(탭·기울기·퀴즈 선택). **서버 메모리에만 보관하고 DB가 없어
  재시작 시 소멸**. 회원가입·로그인 없음
- **타사 전송**: Cloudflare Web Analytics — 쿠키리스 익명 집계(페이지뷰·유입·국가).
  라이브 확인됨(`static.cloudflareinsights.com/beacon.min.js`)
- **수집하지 않는 것**: 이메일·전화번호·위치·연락처·기기 식별자·결제 정보

개인정보처리방침 URL을 요구하면: `https://bokbulbok-party.fly.dev/privacy`

## 자체등급분류 설문 (IARC) — 사실대로

| 문항 영역 | 답 | 근거 |
|---|---|---|
| 폭력성 | 없음 | 구슬 굴리기·퀴즈·반응속도. 캐릭터 간 공격 없음 |
| 선정성 | 없음 | |
| 부적절 언어 | 없음 | 자유 채팅 없음. 닉네임만 입력(서버가 길이·중복 검증) |
| 약물·음주·흡연 | 없음 | 앱 내 묘사·언급 없음 (미니앱용 카피에서 배제) |
| 도박·사행성 | **없음** | 벌칙 정하기는 놀이이고 **재산상 이득을 건 베팅이 아니다**. 확률형 아이템·게임머니 베팅 없음 |
| 공포 | 없음 | |
| **온라인 상호작용(멀티플레이 존재 여부)** | **있음** | 같은 방 참가자끼리 실시간 플레이 |
| **음성·텍스트·이미지·오디오로 상호작용/콘텐츠 교환** | **없음 → `아니요`** | 채팅·음성·이미지/오디오 공유 채널이 **하나도 없다**. 클라→서버 이벤트 전체(`protocol.ts`)에 메시지 계열 없음. 사용자 입력 텍스트는 닉네임(`join`·`host:addPlayer`)뿐이고 닉네임은 표시용 이름이지 통신 채널이 아니다 |
| 차단 / 신고 / 채팅 조정 기능 | **전부 없음** | 위 문항에 `아니요`면 하위 문항으로 나오지 않는다. **있다고 답하면 허위 기재** — 등급 직권 재분류·취소 사유 |
| 상호작용을 초대된 친구로만 제한 | 가능 | 방 코드·QR 초대로만 입장 |
| 위치 정보 공유 | 없음 | |
| 개인정보 공유 | 없음 | 회원가입 없음, 서버는 닉네임만 메모리 보관 |
| 디지털 구매(인앱결제) | 없음 | 무료, 결제 모듈 없음 |

예상 등급: **전체이용가**. "온라인 상호작용 있음"은 등급을 올리기보다 표시 항목으로 붙는 게 보통이다.

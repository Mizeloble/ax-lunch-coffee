# 원스토어 등록 입력값 (등급분류용)

목적은 유통이 아니라 **자체등급분류 번호 취득** — 앱인토스 출시의 법적 요건.
맥락은 [toss-miniapp-review.md](toss-miniapp-review.md) §1-3.

## 등록 절차

[개발자센터](https://dev.onestore.co.kr) → **Apps > 상품현황 > [신규 상품 등록]**

1. **서비스 구분**: `정식 출시` (베타는 등급분류 목적에 맞지 않음)
2. **OS**: `Android`
3. **기본 정보**
   - 상품제목(최대 50자): `복불복파티`
   - 기본언어: 한국어
   - **패키지 네임: `com.mizeloble.bokbulbok`** ⚠️ **등록 후 변경 불가** — APK에 서명된 값과 반드시 일치
4. **카테고리**: **게임** 계열로 선택. 게임 카테고리는 게임물만 서비스 가능하고,
   나중에 다른 카테고리에서 게임으로 바꾸면 재검증을 다시 받는다 → 처음부터 게임으로.
5. **상세 정보**: 아래 [앱 정보](#앱-정보)의 설명·아이콘·스크린샷 입력
6. **바이너리 업로드**: `app-release-signed.apk`
7. **등급분류(IARC) 설문**: 아래 [설문 답안](#자체등급분류-설문-iarc--사실대로)대로 응답 →
   제출하면 등급이 자동 부여된다(원스토어가 자체등급분류사업자)
8. **검수 요청** → 통과 시 스토어 전시 + 등급분류 번호 확정

> 원스토어 등급으로 앱인토스 제출이 가능한지는 앱인토스 콘솔팀이 "가능하다"고 답변한
> [커뮤니티 스레드](https://techchat-apps-in-toss.toss.im/t/topic/1689)와, 실제로 통과시킨
> [사례](https://techchat-apps-in-toss.toss.im/t/topic/3570)로 확인됨.

## 앱 정보

- **앱 이름**: `복불복파티`
  (앱인토스 등록명과 동일하게 — 나중에 "동일 게임" 증명이 쉬워진다)
- **패키지명**: `com.mizeloble.bokbulbok`
- **카테고리**: 게임 > 캐주얼 (또는 보드/파티 계열)
- **가격**: 무료
- **한 줄 소개**: `모여서 바로 즐기는 복불복 미니게임`

**검색 키워드** (우선순위 순 — 입력 개수 제한이 있으면 앞에서부터 자른다.
앱인토스 "검색 키워드" 칸에도 같은 목록을 쓴다):

```
복불복, 파티게임, 미니게임, 벌칙, 랜덤, 룰렛, 뽑기, 모임게임, 단체게임, 마블레이스, 구슬, 퀴즈, 반응속도, 순발력, 친구, 엠티
```

> ⚠️ **`술게임`·`회식`·`음주` 계열은 넣지 않는다.** 웹 랜딩에는 있지만 여기서는 뺀다 —
> 등급분류 설문에서 "약물·음주 없음"으로 답하는데 키워드에 음주 맥락이 있으면 모순이고,
> 등급이 올라가면 앱인토스의 만 14세 노출 풀에서 빠진다(§자체등급분류 설문, toss-miniapp-review.md §3-1).
> `사다리`도 제외 — 실제로 없는 게임이라 부정확하다.

**상세 설명** (앱인토스와 같은 전연령 카피 — 음주 표현 배제):

```
방 만들기 버튼을 누르면 6자리 방 코드와 초대 QR이 바로 나타납니다. 친구들은 초대 링크나 방 코드 입력으로 들어와 닉네임만 정하면 참가 완료됩니다.

호스트가 시작을 누르면 마블 레이스, 반응속도, 상식 퀴즈, 응원 레이스 같은 미니게임이 펼쳐지고, 참가자 전원의 화면에서 같은 장면이 동시에 재생됩니다. 결과는 서버가 공정하게 결정하기 때문에 누구도 조작할 수 없습니다.

게임이 끝나면 전체 순위와 함께 오늘의 당첨자가 공개됩니다. 결과 카드를 저장해 친구들과 나누거나, 게임을 바꿔서 바로 다음 판을 시작할 수 있습니다.

회원가입 없이 4~12명이 즉석에서 즐길 수 있어 모임, 여행, 게임할 사람 정하기 등 무엇이든 복불복으로 정할 때 좋습니다.
```

## 자체등급분류 설문 (IARC) — 사실대로

| 문항 영역 | 답 | 근거 |
|---|---|---|
| 폭력성 | 없음 | 구슬 굴리기·퀴즈·반응속도. 캐릭터 간 공격 없음 |
| 선정성 | 없음 | |
| 부적절 언어 | 없음 | 자유 채팅 없음. 닉네임만 입력(서버가 길이·중복 검증) |
| 약물·음주·흡연 | 없음 | 앱 내 묘사·언급 없음 (미니앱용 카피에서 배제) |
| 도박·사행성 | **없음** | 벌칙 정하기는 놀이이고 **재산상 이득을 건 베팅이 아니다**. 확률형 아이템·게임머니 베팅 없음 |
| 공포 | 없음 | |
| **온라인 상호작용** | **있음** | 같은 방 참가자끼리 실시간 멀티플레이 |
| 사용자 생성 콘텐츠 | 제한적 | 닉네임 입력만. 자유 텍스트 공유·채팅 없음 |
| 위치 정보 공유 | 없음 | |
| 개인정보 공유 | 없음 | 회원가입 없음, 서버는 닉네임만 메모리 보관 |
| 디지털 구매(인앱결제) | 없음 | 무료, 결제 모듈 없음 |

예상 등급: **전체이용가**. "온라인 상호작용 있음"은 등급을 올리기보다 표시 항목으로 붙는 게 보통이다.

## 심사 통과 후 (앱인토스 콘솔 3단계 입력용) — 반드시 기록

- [ ] 스토어 링크(원스토어 앱 URL)
- [ ] **등급분류 번호**
- [ ] **등급분류 일자**
- [ ] 자체등급분류사업자명: `원스토어`
- [ ] 앱마켓 게임등록자명 = 원스토어 가입 시 입력한 이름 (앱인토스와 **글자 단위 일치** 필요)
- [ ] 대표자명·주소·전화번호 (원스토어 등록 정보와 동일하게)

> 게임물관리위원회 DB 등재는 심사 통과 후 하루쯤 걸린다
> ([앱인토스 커뮤니티 사례](https://techchat-apps-in-toss.toss.im/t/topic/3570)) — 앱인토스 제출은 그 다음 날.

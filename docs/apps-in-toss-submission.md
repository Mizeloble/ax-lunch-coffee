## 4단계 · 번들 업로드 → 토스앱 테스트 → 검수 요청

1. `.ait` 번들 업로드: `miniapp/bokbulbok-party.ait`
   - 재빌드가 필요하면: `cd miniapp && VITE_SERVER_URL=https://bokbulbok-party.fly.dev npm run build:ait`
2. 콘솔 QR로 **토스앱 테스트 1회 이상** — 이걸 해야 검토 요청 버튼이 활성화된다
3. 검수 요청 (3~5영업일, 한 번에 한 버전)

### 검수 요청 전 자가 점검 (반려 빈발 항목)

- [x] 사운드 재생 + On/Off 설정 — 구현·실기기 확인 완료
- [x] 진동(햅틱) — 구현·실기기 확인 완료
- [x] 종료 확인 모달 / OS 뒤로가기 차단 — 구현 완료 (**Android 실기기 확인 미완**)
- [x] 게임 중 화면 유지, 딥링크 진입, hostToken 보존
- [x] 우측 상단 닫기 버튼 미가림 — 사운드 토글을 좌하단으로 이동(v2.33.1)

- [ ] Safe Area(노치·홈 인디케이터) 침범 없음 — 실기기 확인
- ⚠️ 다크 테마 — 가이드는 라이트 기준이나 게임 트랙은 풀스크린 자유도가 있다. 반려되면 그때 대응
